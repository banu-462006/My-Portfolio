## ⚡ How to Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/banu-462006/Portfolio.git
cd Portfolio
```

### 2. Launch Local Server
Open PowerShell or Terminal and run:
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000` in your web browser.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Navigate to your repository settings on GitHub:
   `https://github.com/banu-462006/Portfolio/settings/pages`
2. Under **Build and deployment** > **Branch**:
   * Select `main` (or `master`)
   * Folder: `/ (root)`
   * Click **Save**
3. In a few moments, your portfolio will be live at:
   ```
   https://banu-462006.github.io/Portfolio/
   ```
